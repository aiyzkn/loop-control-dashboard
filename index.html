loop-control ダッシュボード

指令リポジトリ のタスクと PC の状況を表示します。トークンに書き込みの権限があれば、タスクの書き換え・並べ替えもできます（送る前に差分を見せます）。組織 のメンバーだけが使えます。

トークンの作り方
  1. GitHub の Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Resource owner: aiyzkn。Repository access: Only select repositories → loop-control
  3. Repository permissions: 見るだけなら Contents: Read-only、書き換え・並べ替えもするなら Contents: Read and write（Metadata: Read-only は自動で付く）
  4. Organization permissions: Members: Read-only（組織への所属を確かめるため）
  5. 有効期限は短めにする。組織の設定で承認が要る場合は、管理者の承認を待つ

トークンは、このブラウザの中（既定はタブを閉じるまで）にだけ置き、api.github.com にだけ送ります。書き込みは、確認の画面で「送る」を押したときだけです。
